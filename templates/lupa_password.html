Cara memulihkan

  2. Unduh berkas finansial.db dari hosting Anda, biasanya lewat File Manager
  3. Jalankan alatnya, pilih berkas itu, lalu tekan tombol pemulihan
  4. Catat password barunya, lalu unggah kembali berkasnya ke hosting
